# engines

- `PudimEngine.lua` (**v0.5**): vec2, palette, rotatable textured rectangles (`ttri`), `rotatespr`, glitch, `text_block`, init/update/draw cycle.
- `dreamworld.lua` (v0.1): game on top of engine 0.5 (`game_info` at the top, layers, characters).

Earlier versions (0.4) are embedded in `projetos_inacabado/rpg.lua` and `daviSystem2`.
