# genericRpg

Generic RPG (`rpg.lua`) using `vec2`, `lerp`, `check_colision` (through `fget`/`mget`) and `erroLibary`.
Source artwork in Krita: `sprs.kra`, `tiles.kra` (+ `.png` exports). The `.png~`/`.kra~` files are Krita backups and were not included.
It uses `H:/Meu Drive/tic-80/appdata/` in `addPath`.
