# daviSystem

SO fictício em TIC-80.

- **daviSystem1/**: workspace com wallpaper, janelas, taskbar com data, menu iniciar e `createAPP(app, iconString)` (ícone = string hexa de 64 caracteres). `sprPixStr.lua` desenha sprites a partir de strings; `Backup/` guarda uma versão anterior.
- **daviSystem2/**: reescrita sobre a engine v0.4 (vec2, `texrect`, `sprtex`, `new_program`). Tem `.lua` e `.tic`.

**Atenção:** `daviSystem2/daviSystem2.lua` já tinha um erro de sintaxe (`function arguments expected near 'end'`, por volta da linha 155 original) antes dos comentários; o `.tic` é a versão a usar.
